# Design System

The visual language should feel futuristic, premium and minimal.

The inspiration is NOT the layout of the reference.

The inspiration is the quality of motion, depth and realism.

## Color Palette

Follow the provided project color theme.

Do not invent new primary colors.

Only create lighter and darker variations when needed.

Use gradients sparingly.

Accent colors should only highlight important actions.

## Components

Components should not look like templates.

Buttons

• Soft glow
• Premium hover
• Micro interactions
• Magnetic hover
• Animated borders

Cards

• Glass morphism
• Floating effect
• Soft reflections
• Layered depth

Icons

• Lucide
• Thin stroke
• Consistent sizing

---

## Layout

Large spacing.

Asymmetrical composition.

Broken grid where appropriate.

Content should breathe.

Avoid cramped layouts.

---

## Motion

Motion should feel physical.

Preferred techniques

• Framer Motion
• Scroll timelines
• Perspective transforms
• Layered parallax
• 3D rotation
• Object floating
• Mouse parallax
• Scroll reveals
• SVG morphing
• Dynamic blur
• Motion blur
• Glass transitions

Avoid

❌ Bounce animations

❌ Random floating

❌ Repeated fade-ins

❌ Generic easing

Every section should introduce a unique interaction.

---

## 3D

Use React Three Fiber where it genuinely enhances the experience.

Possible elements

• Floating glass shapes

• Interactive particles

• Animated gradient lighting

• Depth of field

• Environment lighting

• Mouse reactive camera

• Smooth camera movement

The 3D should complement the content, not distract from it.

---

## Responsiveness

Desktop-first design.

Tablet optimized.

Mobile should retain the premium experience instead of simply stacking content.

---

## Quality Standard
